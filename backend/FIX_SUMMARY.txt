================================================================================
                          COMMON ISSUES
================================================================================

ISSUE 1: Missing x-api-key header
  ├─ Symptom: "API key is required"
  ├─ Cause: Line not in ESP8266 code
  └─ Fix: Add http.addHeader("x-api-key", apiKey);

ISSUE 2: Empty API key
  ├─ Symptom: Registration shows no API Key
  ├─ Cause: Registration endpoint not called or failed
  └─ Fix: Type REGISTER in Serial Monitor

ISSUE 3: Invalid API key
  ├─ Symptom: "Invalid API key. Pump not found"
  ├─ Cause: API key doesn't exist in database
  └─ Fix: Re-register pump (REGISTER command)

ISSUE 4: WiFi disconnected
  ├─ Symptom: Can't reach backend
  ├─ Cause: WiFi credentials wrong or signal lost
  └─ Fix: Check WIFI_SSID and WIFI_PASSWORD in code

ISSUE 5: Pump ID mismatch
  ├─ Symptom: "Pump ID mismatch" error
  ├─ Cause: Body pumpId ≠ registered pumpId
  └─ Fix: Ensure IDs match exactly
